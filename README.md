## 📖 Overview

**The Coffee Journal** is a personal, editorial-style web application built from the ground up to chronicle coffee lots, cupping notes, and extraction protocols across India and the globe. 

Designed with an aesthetic inspired by vintage print journals and specialty coffee packaging, the project uses warm cream tones, bespoke serif typography, debossed archival cards, and wax/ink stamp badges.

---

## ✨ Features

- **Coffee Passport Archive:**
  - 23+ cataloged micro-lots with roaster credits, origin terroir, altitude, process details, and cupping scores.
  - Interactive tactile **TCJ APPROVED** vintage stamps on every entry.
  - Live category filters: *All Lots*, *Anaerobic & Yeast*, *Naturals*, *Washed*, *Barrel Aged*, and *Blends*.
  - Clean pagination showing 6 lots initially with an incremental **View More** button.
  - Interactive cupping modals with dynamic **Sensory Radar Brew Maps** (Acidity, Sweetness, Body, Clarity, Aftertaste) rendered via inline mathematical SVG calculations.

- **Brewing Laboratory:**
  - Dedicated gear guides covering 6 core extraction devices: **AeroPress**, **French Press**, **Moka Pot**, **South Indian Filter**, **Cold Brew**, and **Coffee Dripper Machine**.
  - Multi-recipe interactive modal system offering at least two dialed-in protocols per brewer (e.g., Inverted vs. Competition Bypass, Hoffmann Immersion vs. Traditional Steep).
  - Exact measurements for dose, water volume, ratio, micron grind size, temperature, and extraction timings.

- **Curated Gallery & Lightbox:**
  - Archival photo grid with an interactive modal carousel.
  - Keyboard navigation ($\leftarrow$ / $\rightarrow$ / `Escape`) and smooth arrow controls.
  - Paginated gallery rendering 6 photos initially with incremental load.

- **Curriculum Vitae Integration:**
  - Integrated editorial **Download Resume** button configured for instant single-click PDF downloads.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Custom CSS3 (Modern Flexbox, CSS Grid, custom properties, paper-grain SVG filters)
- **Engine:** Vanilla JavaScript (ES6+) — zero external runtime frameworks or heavy libraries for maximum speed and sub-second load times
- **Fonts:** *Instrument Serif*, *Cinzel*, and *Plus Jakarta Sans* via Google Fonts
- **Deployment:** GitHub Pages
